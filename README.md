# 导航网站（nav_ycz_me）

一个开箱即用的导航网站。支持本地数据持久化（IndexedDB）、数据管理（导入/导出、恢复默认、与后端同步）、以及多页面工具与演示。项目基于 Node.js + Koa + EJS 前端模板，前端依赖 Vue.js 与 Axios。

## 功能概览
- 首页导航与搜索
- 数据管理：接口管理、测试拉取、恢复默认、导出/导入、同步到后端
- 多页面：工具页、Emoji 图标页、AI Chat 页
- 本地持久化：IndexedDB 存储网站、分类、搜索引擎等数据

## 快速开始
1. 安装依赖：`npm install`
2. 启动服务：`npm start`
3. 访问站点：`http://localhost:3002`

## 主要页面
- `/` 首页
- `/data-manager` 数据管理
- `/tools` 工具页
- `/emoji` Emoji 图标页
- `/ai-chat` AI Chat 演示

## 数据管理使用说明
- 自定义默认 API 地址：
  - 在“后台接口管理”区域填写自定义默认数据源地址，可点击“测试数据拉取”验证。
  - 可“保存”以便持久化或“清空”恢复为空。
- 恢复默认：
  - 留空时，将从 `https://admin.ycz.me/api/site.index/index` 拉取默认数据并恢复到本地。
  - 填写自定义地址时，将从该地址拉取默认数据并恢复到本地。
  - 系统会自动兼容常见的 `json.data` 包裹响应结构。
- 导出数据：
  - 将当前本地数据导出为 JSON 文件下载保存。
- 还原数据：
  - 上传之前导出的 JSON 文件，覆盖本地数据。
- 同步到后端：
  - 若已配置对应后端接口，可将本地数据推送到后端（接口与字段需与后端约定）。

## 配置与环境
- Node.js 版本：推荐 18+（开发环境已在 Windows 下验证）
- 默认端口：`3002`（如需修改，可在 `app.js` 中调整）
- 可选 `.env`：
  - `DEFAULT_SITE` 可设置默认数据源地址（不设置时，页面留空恢复默认会回退到 `https://admin.ycz.me/api/site.index/index`）。

## 接口与 API（示例）
- `POST /api/websites` 新增网站（详见 `routes/index.js` 与 `controllers/ApiController.js`）
- 其余接口可按需扩展（例如分类、搜索引擎、站点批量同步等），与后端约定字段和鉴权方案。

## 部署建议
- 生产环境可使用 PM2 或容器编排运行，建议使用反向代理（如 Nginx）暴露端口。
- 若与后端联动，建议为数据同步接口设置鉴权（Token、签名或白名单）。
